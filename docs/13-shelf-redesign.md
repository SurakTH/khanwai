# ชั้นหนังสือใหม่ — 0.8.0

ผู้ใช้ต้องการรื้อหน้าชั้นที่เริ่มรกให้สวยและใช้ง่ายขึ้น ทำในแอพเดิม ไม่เพิ่มหน้าแสดงฟีเจอร์ทดลองหรือบริการใหม่

## ลำดับบนหน้าจอ

1. ชื่อหน้า จำนวนเรื่อง/ฉบับและจำนวนหนังสือแบบบรรทัดเดียว พร้อมปุ่มเพิ่มหนังสือเดิม
2. ค้นหาและปุ่มกรองเดียว เปิดประเภท รูปแบบ ชุดไม่ครบ ที่เก็บ และแท็กในพื้นที่เดียว
3. แท็บทั้งหมด / มีแล้ว / รอส่ง / อยากซื้อ สำหรับเปลี่ยนสถานะที่ดูบ่อย ตัวกรองการอ่านอยู่ในปุ่มกรองตาม 0.8.6
4. จำนวนผลลัพธ์ มุมมองปก/รายการย่อ เรียงตาม และเมนู ••• สำหรับเลือกหลายรายการ
5. ปกหนังสือ ชื่อ ผู้เขียน และสถานะที่จำเป็น แตะการ์ดเพื่อเปิดรายละเอียดเดิม

ปกใช้พื้นที่กระดาษโทนอุ่น มีระยะห่างและเงาหนังสือ ภาพที่บันทึกจริงแสดงเต็มสัดส่วน ไม่ตัดข้อความบนปก รูปแบบ/ฉบับ/ภาษาอยู่บรรทัดเดียว ไม่แสดงแท็กและข้อมูลการอ่านเริ่มต้นซ้ำบนปกทุกใบ รายการย่อและรายละเอียดแสดงข้อมูลเหล่านี้ครบเหมือนเดิม

## การใช้เครื่องมือ

- กรองเปิดแบบ inline ด้วย native details ไม่ซ้อน dialog กดดูผลลัพธ์เพื่อปิดและไปยังผลค้น มีป้ายตัวกรองที่ใช้อยู่ให้เอาออกทีละตัว และล้างทั้งหมดได้
- ตัวกรองยังคำนวณทันทีขณะเลือก ไม่ต้องรอยืนยันข้อมูล ปุ่มดูผลลัพธ์มีหน้าที่ปิดเครื่องมือและพาไปอ่านผล
- เมนู ••• → เลือกหลายรายการ แสดง checkbox และแถบจัดการเมื่อจำเป็น แตะทั้งการ์ดเพื่อเลือกได้ กดเลิกเลือกเพื่อกลับไปเปิดรายละเอียดตามปกติ
- ผลค้นว่างอธิบายว่าหนังสือที่ถูกกรองยังอยู่บนชั้น มีปุ่มล้างคำค้นและตัวกรอง ไม่ชวนเพิ่มซ้ำจากผลกรองว่าง
- จำมุมมองและลำดับต่อบัญชีในเบราว์เซอร์เดิม ไม่มีการบันทึกการเปิดเครื่องมือเป็น mutation ข้อมูลหนังสือ

## ผลตรวจภาพ

ใช้ข้อมูลตัวอย่างเดียวกัน บัญชีและฐานทดสอบแยกจากข้อมูลผู้ใช้:

| หน้าจอ | จุดเริ่มปกเดิม | จุดเริ่มปกใหม่ |
| --- | ---: | ---: |
| มือถือ 390 × 844 | 644px | 359px |
| คอม 1440 × 1000 | 650px | 423px |
| จอแคบ 320 × 800 | 692px | 335px |

มือถือ 390px เห็นปก ชื่อ ผู้เขียน และสถานะของสองเรื่องแรกในจอแรก ไม่มีการเลื่อนแนวนอนที่ 320px รายการย่อยังเป็นคอลัมน์เดียว ตัวเลขเป็น geometry ของ fixture ไม่ใช่ผลทดสอบผู้ใช้หรือการรับรอง Safari จริง

ภาพก่อน/หลังอยู่ใน screenshots/shelf-before-mobile.png, shelf-after-mobile.png, shelf-before-desktop.png และ shelf-after-desktop.png สร้างภาพใหม่จาก source ปัจจุบันด้วย `node tests/preview-shelf.mjs after` สคริปต์สร้างและลบฐานข้อมูลชั่วคราวของตัวเอง พร้อมภาพตัวกรอง shelf-after-filters-mobile.png และรายการย่อ shelf-after-list-mobile.png

## สำหรับพัฒนาต่อ

- public/shelf-view.js จัด markup/ตัวเลือกและสรุปจำนวน, public/shelf.css จำกัดรูปแบบเฉพาะชั้นหนังสือ
- public/app.js คง state/filter/sort/event และ mutation/outbox เดิม ไม่มี schema หรือ API ใหม่
- service worker shell-v20 รวมไฟล์ใหม่ และคง flow แจ้งอัปเดตเดิมเมื่อมีฟอร์มหรือคิวค้าง
- native details/summary, label ของปุ่มไอคอน, aria-pressed, focus เมื่อปิดเครื่องมือ และ touch target มือถืออย่างน้อย 44px; เคารพ reduced motion
- การอ่าน ค่าเริ่มต้นยังไม่อ่าน บ็อกซ์ จำนวนสำเนา การแยกฉบับ/ebook และ owner isolation คงตาม docs/11 และ docs/12

หลักฐานทดสอบและการอัปเดต instance อยู่ใน docs/08-prototype.md ไม่ถือว่าการทดสอบ Chromium mobile emulation แทนการลอง iPhone/Android จริงได้


## ปรับขอบรอบปกใน 0.8.2

ตามคำขอหลังใช้งาน ลดเฉพาะกรอบ gallery ให้โอบปกแทนแผ่นพื้นหลังกว้างเต็มคอลัมน์: max-width 188px / width 88%, padding 8–10px, ความสูงตามปก และให้ปกขยายเต็มพื้นที่ด้านใน ยังคง object-fit contain และ thumbnail ของรายการย่อเดิม ป้ายตัวอย่างอยู่เหนือกรอบ ภาพ shelf-after-*.png เป็นภาพจาก source ปัจจุบัน ส่วนค่า geometry ในตารางข้างบนเป็น baseline ของรอบ 0.8.0 ไม่ใช่การวัดขนาดปก 0.8.2


## ข้อกำหนดที่แก้ไขชัดเจนใน 0.8.3

แทนที่การย่อกรอบของ 0.8.2 ซึ่งเป็นการเข้าใจผิดของผู้ช่วย: ผู้ใช้ต้องการกรอบขนาดเดิมเต็มคอลัมน์ ตรงแนวข้อความ ขยายเฉพาะภาพในกรอบ ปัจจุบันคืนอัตราส่วนและความกว้างกรอบเดิม ลด padding ภายในและขยายปกตามความสูง โดยคงสัดส่วนและ contain; ไม่เปลี่ยนรายการย่อหรือข้อมูลหนังสือ preview utility ตรวจขนาด/แนวกรอบและอัตราส่วนปกที่ render แล้วด้วย


## ตัวกรองการอ่านใน 0.8.4

ช่องการอ่าน: ทั้งหมดอยู่ด้านขวาแถว ownership บนคอม และอีกบรรทัดบนมือถือ เลือกทั้งหมด / ยังไม่อ่าน / อยากอ่าน / กำลังอ่าน / อ่านแล้วได้ทันที เอา select เดิมออกจากแผงกรองแล้ว ตัวกรองรวมเงื่อนไขเดิม ไม่สร้าง mutation หรือบันทึกว่าอ่านหนังสือ เลือกทั้งหมดหรือล้างป้ายการอ่านจะคง tag/location/เงื่อนไขอื่น ชุดที่มีเล่มอ่านแล้วและยังไม่อ่านเจอได้ในทั้งสองตัวกรองตาม entry/member และมีสรุปการอ่านผสมบนการ์ด ไม่อ้างว่าทั้งชุดอ่านครบ


## จัดแถวเครื่องมือใหม่ใน 0.8.5

ผู้ใช้ไม่พอใจหน้าตาช่องการอ่านของ 0.8.4 ทั้งมือถือและคอม จึงแทนที่ช่องที่ลอยแยกข้างแท็บด้วยแถวเครื่องมือเดียว: มือถือ/พื้นที่แคบวางการอ่านและเรียงเป็นสองช่องโทนอ่อน กว้างเท่ากัน ด้านล่างเป็นจำนวนผลลัพธ์/มุมมอง/จัดการ; คอมพื้นที่กว้างใช้หนึ่งบรรทัด ไม่มีกรอบฟอร์มสีขาวแยกชิ้น ใช้ CSS grid responsive ไม่มีสำเนา control หรือ JavaScript สลับ DOM ตามความกว้าง

ที่ 320/375/390/430px ขอบสองช่องตรงแนวสองคอลัมน์หนังสือ ช่อง native select มีตัวอักษร 16px/สูง 44px; พื้นที่แคบรวม tablet ถึง 900px ใช้แบบสองแถวเพื่อไม่บีบเครื่องมือเมื่อ sidebar ยังแสดง กว้างกว่า 900px กลับเป็นบรรทัดเดียว คง readingFilter และ sort เดิม สถานะครบ 4 แบบ/ทั้งหมด เคลียร์ร่วมกับตัวกรองอื่นได้เหมือนเดิม กรอบปกเต็มคอลัมน์ตาม 0.8.3 ไม่เปลี่ยน

ภาพก่อนแก้: reading-filter-before-mobile.png / reading-filter-before-desktop.png; ภาพปัจจุบัน: shelf-after-mobile.png / shelf-after-desktop.png และ reading-toolbar-320.png, reading-toolbar-375.png, reading-toolbar-430.png, reading-toolbar-1024.png, reading-toolbar-selected-mobile.png ใน screenshots/ สร้างด้วย tests/preview-shelf.mjs บัญชี/ข้อมูลทั้งหมดเป็น fixture แยกจากผู้ใช้


## คืนแบบเดิมตามผู้ใช้ใน 0.8.6 — ใช้ส่วนนี้เป็นสถานะปัจจุบัน

ผู้ใช้ส่งภาพจาก iPhone และยืนยันว่าชอบแบบก่อนเพิ่มช่องการอ่าน จึงคืน public/shelf.css และ public/shelf-view.js จาก image 0.8.3 โดยตรง ยกเลิก quick filter และคู่ช่องอ่าน/เรียงของ 0.8.4–0.8.5 ทั้งบนมือถือและคอม ให้จำนวนผลลัพธ์/มุมมอง/เรียง/จัดการกลับอยู่แถวเดียวเดิม ตัวกรองการอ่านอยู่ในแผงกรองแบบก่อนหน้า สถานะการอ่านทั้งหมดและข้อมูลรายเล่ม/บ็อกซ์คงเดิม ไม่คืนฐานข้อมูลหรือย้อนฟีเจอร์อื่น

ภาพ shelf-after-mobile.png / shelf-after-desktop.png เป็นหน้าที่คืนแล้ว ปกแรกกลับไป y=359 บนจอ 390px, y=335 บนจอ 320px และ y=423 บนคอม 1440px utility ตรวจภาพรวมและ toolbar แถวเดียวไม่เกิน 48px ทุกขนาดที่ตรวจ ไม่เพิ่ม quick filter ภายนอกอีกโดยไม่ได้รับคำขอใหม่


## 0.10.3 — บรรทัดใต้ปกแสดงหมวดหมู่

ผู้ใช้ขอแทนฉบับด้วยหมวดหมู่บนการ์ดชั้น จึงแสดง รูปแบบ · หมวดหมู่ · ภาษา ทั้ง gallery และ list ผ่าน card เดิม ไม่เปลี่ยนข้อมูล edition หรือ layout/กรอบปก รายละเอียดและการแก้ข้อมูลยังคงฉบับเดิม
