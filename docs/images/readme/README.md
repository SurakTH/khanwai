# ภาพประกอบ README

ภาพในโฟลเดอร์นี้ตั้งใจเผยแพร่พร้อม README ตามคำขอผู้ใช้ เป็นภาพแอพจริงจากฐานข้อมูลและบัญชีชั่วคราวที่สคริปต์สร้างขึ้น

- ชื่อหนังสือ ผู้เขียน และปก CSS ใช้ข้อมูลสมมติจาก `seedState()` สคริปต์เชื่อมฉบับหนังสือเล่มและ ebook ในฐานชั่วคราวเพื่อถ่ายภาพหน้ารวม
- บัญชีใช้ `reader@example.test` ซึ่งเป็นข้อมูลทดสอบ ไม่ใช่อีเมลผู้ใช้จริง
- ไม่อ่านฐานข้อมูล รูปหนังสือ ไฟล์แนบ หรือ `.env` ของผู้ใช้ ไม่เรียก ISBN provider ภายนอก
- `overview.jpg` จัดกรอบภาพคอมและมือถือด้วย HTML/CSS ส่วน `linked-editions.jpg` และภาพ PNG ถ่ายจากหน้าจอแอพ

สร้างใหม่จากราก repository หลังติดตั้ง Chromium และ dependencies:

```sh
node tests/preview-readme.mjs
```

ตรวจภาพและข้อความก่อนเผยแพร่ทุกครั้ง ภาพพัฒนาหรือภาพที่ผู้ใช้แนบยังอยู่ใน `docs/screenshots/` และไม่รวมใน Git อย่าคัดลอกภาพเหล่านั้นมาแทนภาพสาธารณะโดยอัตโนมัติ
