# เอกสารคั่นไว้ — เริ่มอ่านที่นี่

เอกสารโครงสร้างปัจจุบันตรวจเทียบกับซอร์ส **0.10.3** เมื่อ 31 ตุลาคม 2026 ไม่ต้องอ่านบันทึกทุกเวอร์ชันก่อนจึงจะเข้าใจระบบ

## อยากรู้เรื่องไหน

| ถ้าอยากรู้ว่า… | อ่านไฟล์นี้ |
| --- | --- |
| เว็บทำอะไร ใช้เทคโนโลยีอะไร แต่ละไฟล์รับผิดชอบอะไร | [18 — ภาพรวมระบบและโครงสร้างโค้ด](18-system-overview.md) |
| ใช้ข้อมูลแบบไหน ตารางไหนเก็บอะไร รูปอยู่ที่ไหน มีตัวอย่าง JSON ไหม | [19 — ข้อมูลและฐานข้อมูลที่ใช้จริง](19-data-and-storage.md) |
| กดบันทึกแล้วเกิดอะไร ออฟไลน์ซิงก์อย่างไร API มีอะไรบ้าง | [20 — API และการซิงก์](20-api-and-sync.md) |
| จะติดตั้ง อัปเดต ตั้งโดเมน สำรอง หรือย้ายเซิร์ฟเวอร์ | [09 — Docker และการดูแลเซิร์ฟเวอร์](09-docker.md) |
| จะเปิดแอพใช้ทันที | [README หลัก](../README.md#เริ่มใช้ด้วย-docker) |

**ถ้าเพิ่งมาดูโครงการ:** อ่าน **18 → 19 → 20** แล้วค่อยเปิดคู่มือเฉพาะส่วนที่สนใจ

ข้อเท็จจริงสำคัญ: ใช้เว็บ vanilla HTML/CSS/JS กับ Node.js ใน container เดียว, SQLite เก็บข้อมูลบัญชี/รายการ, รูปจริงอยู่เป็นไฟล์ใน volume, IndexedDB เก็บสำเนาและคิวออฟไลน์ในเบราว์เซอร์ ไม่มีฐาน Work/Edition กลางหรือระบบ AI อยู่เบื้องหลัง
