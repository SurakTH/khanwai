# รายละเอียดหนังสือและรายเล่ม — 0.8.1

ผู้ใช้ขอปรับ UX/UI ของหน้ารายละเอียด โดยเฉพาะแถวรายเล่มที่มี select และปุ่มหลายอันเรียงติดกัน จัดเป็นการ์ดเล่มใน dialog เดิม ไม่เพิ่มหน้า เมนูหลัก หรือบริการ

## การจัดหน้า

- ส่วนชื่อเรื่องและภาพชุดกระชับขึ้น ปุ่มแก้ไขข้อมูลเรื่อง/ฉบับและเปลี่ยนภาพชุดยังอยู่ด้านบน
- การอ่านทั้งชุดเป็นแผงเดียว มีสรุปการอ่านและปุ่มอ่านแล้ว / ยังไม่อ่าน / อยากอ่าน พร้อมข้อความระบุว่าเปลี่ยนทุกเล่มที่บันทึกในฉบับนี้รวมบ็อกซ์ หากแต่ละเล่มอ่านต่างกัน ไม่แสดงปุ่มใดว่าเลือกทั้งชุดแล้ว
- หัวข้อเล่มในฉบับนี้แสดงจำนวน **รายการที่บันทึก** ไม่อ้างว่าเป็นจำนวนเล่มไม่ซ้ำหรือจำนวนสำเนา ปุ่มเพิ่มเล่มอยู่ข้างหัวข้อ เข้า flow เพิ่มเดิม
- แผนที่เลขเล่มเป็นภาพรวมอ่านอย่างเดียว ย่อขนาดและแยก legend มีแล้ว/รอส่ง/ยังไม่มี แสดง target note ตามเดิม ไม่เดาวันออกหนังสือ
- แต่ละ entry เป็นการ์ด: เลขเล่มหรือรูปที่บันทึกไว้ ชื่อเล่ม จำนวนสำเนา ที่เก็บ ISBN และสมาชิกบ็อกซ์เมื่อมี
- ช่องการครอบครองและการอ่านมี label แยกกัน วางแนวนอนบนคอมและบรรทัดถัดไปสองคอลัมน์บนมือถือ ใช้ native select และตัวอักษร 16px บนมือถือ
- แก้ไขข้อมูล / รูปปก / ลบรายการ อยู่ใน native details ชื่อจัดการเล่ม… ของ entry นั้น แสดงเมนูทีละอัน ปิดเมื่อแตะข้างนอกหรือ Escape; Escape ครั้งแรกปิดเมนูและคืน focus โดยยังไม่ปิด dialog ลบยังมี confirmation เดิม
- ปิดหน้ารายละเอียดที่ไม่ได้แก้ข้อมูลแล้วไม่วาดหน้าค้นหาซ้ำจนขัด focus; ถ้ามีข้อมูลจากอีกเครื่องเข้ามาระหว่างเปิด dialog จะอัปเดตหน้าหลักหลังปิด
- ชื่อ dialog และปุ่มปิดติดด้านบนเมื่อเลื่อน เปลี่ยนการอ่านหรือการครอบครองแล้วคงตำแหน่งเลื่อน/focus และส่วนสมาชิกบ็อกซ์ที่กางไว้

## ข้อมูลและข้อกำหนดเดิม

การจัดหน้าไม่เปลี่ยน ID, ownership, quantity, ISBN, target หรือ metadataSeed ไม่สร้างเล่มเดี่ยวจาก box members สถานะการอ่านว่างใช้ unread ตาม docs/12 และคงสถานะที่กำหนดไว้ กล่องที่อ่านต่างกันยังแสดงต่างกันแต่ละเล่ม

ใช้ mutation/outbox/revision bases และ owner checks เดิม การเปิด dialog/เมนูไม่สร้างการแก้ข้อมูล ภาพยังมาจากไฟล์ส่วนตัวของบัญชี ไม่ส่งภาพหรือข้อมูลไป provider ใหม่ ไม่มี schema migration, API หรือ dependency เพิ่ม

## โครงสร้างและตรวจรับ

หลักฐานภาพจากบัญชีและฐานข้อมูลชั่วคราว: screenshots/detail-after-desktop.png, detail-after-mobile.png, detail-volumes-desktop.png และ detail-volumes-mobile.png สร้างใหม่ด้วย `node tests/preview-detail.mjs` ไม่ใช้ข้อมูลหรือภาพส่วนตัวจากบัญชีจริง
