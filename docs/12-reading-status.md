# สถานะการอ่าน — 0.7.1

ผู้ใช้ขออ่านแล้ว/ยังไม่อ่าน/คิดจะอ่าน เพิ่มมิติการอ่านแยกจากสถานะ owned/ordered/wishlist และรูปแบบ physical/ebook โดยไม่เพิ่มเมนูหลัก

## ข้อมูลและความหมาย

- `entry.readingStatus?`: `unread` ยังไม่อ่าน, `planned` อยากอ่าน, `reading` กำลังอ่าน, `read` อ่านแล้ว; ค่าว่างหรือไม่มี field ใช้ค่าเริ่มต้นยังไม่อ่านตามคำขอผู้ใช้ใน 0.7.1 คำนวณตอนแสดงผลและกรอง ไม่เขียนข้อมูลเก่าทั้งชั้นย้อนหลัง และคงสถานะ read/planned/reading ที่เลือกไว้แล้ว
- บันทึกใหม่ draft เดิม และ CSV ที่ไม่ระบุการอ่าน ใช้ค่าเริ่มต้นยังไม่อ่านเช่นกัน
- `entry.readingByMember?`: เฉพาะ box เป็น object label → readingStatus (รวมค่าว่าง) สำหรับแต่ละสมาชิก ถ้าไม่ override ใช้ readingStatus ของบ็อกซ์ เมื่อสถานะในบ็อกซ์ต่างกัน ช่องภาพรวมแสดง “ต่างกันแต่ละเล่ม” แทนการอ้างว่าทั้งบ็อกซ์ยังไม่อ่านหรืออ่านแล้ว
- ตัวอย่าง box `{ members:['1','2','3'], readingStatus:'unread', readingByMember:{'1':'read','2':'planned'} }` หมายถึงอ่าน 1 แล้ว อยากอ่าน 2 และ 3 ยังไม่อ่าน ไม่สร้าง entry เล่มเดี่ยวเพิ่ม
- เปลี่ยนการอ่านทั้งบ็อกซ์หรือเลือกแก้ reading ใน bulk จะล้าง override ของแต่ละเล่มให้ใช้ค่าเดียวกัน มี label และ preview บอกขอบเขต ส่วนแก้ที่เก็บ/ISBN/ชื่อบ็อกซ์ไม่ล้างการอ่านรายเล่ม การเอาสมาชิกออกในฟอร์มแก้ไขจะตัด override ที่ไม่อยู่ในบ็อกซ์แล้วด้วย
- การอ่านไม่ยืนยันว่าเป็นเจ้าของ อ่านแล้ว + อยากซื้อ ใช้ได้ เช่น เคยอ่านที่อื่นแล้ว ข้อมูลแต่ละฉบับ ภาษา รูปแบบ แยกกัน ไม่ทำให้การเตือนซ้ำหรือจำนวนในชั้นเปลี่ยน
- สรุปบนการ์ดนับเลขเล่มที่มี entry จริง ไม่รวมเลขเป้าหมายในอนาคต ถ้ามีหลายสำเนา label เดียว เลือกสถานะที่ไปไกลกว่า read > reading > planned > unread > unknown เพื่อไม่ให้สำเนาอีกเล่มล้างประวัติที่เคยอ่าน ส่วนแต่ละ entry ยังเก็บสถานะของตัวเอง

## ใช้งาน

ในหน้ารายละเอียดชุดมีปุ่ม อ่านแล้ว / ยังไม่อ่าน / อยากอ่าน ใช้กับ entry ทุกอันในฉบับนี้ รวมสมาชิกบ็อกซ์ ไม่เพิ่ม entry ตาม target หรือ metadataSeed ไม่แตะรูปแบบอื่น ISBN จำนวนสำเนา หรือ ownership กดแล้วใช้ mutation เดียวกับ revision bases ของหน้าที่เปิดอยู่ และบอกว่ายังรอเซิร์ฟเวอร์ยืนยัน ปุ่มมี aria-pressed เมื่อทุกเล่มเหมือนกัน ถ้าไม่มี entry ปุ่มจะปิดใช้งาน

1. ตอนเพิ่มทีละเล่ม/หลายเล่มเลือกสถานะการอ่าน เก็บผ่านถาดและการสลับโหมดได้ เพิ่มเล่มถัดไปต่อจะเริ่มยังไม่อ่าน ไม่คัดลอกสถานะอ่านแล้วของเล่มก่อน
2. ในรายละเอียดเปลี่ยนการอ่านข้างรายการได้ทันที หรือกดแก้ข้อมูลเล่ม สำหรับบ็อกซ์กาง “การอ่านแต่ละเล่มใน...” แล้วเลือกแต่ละเล่ม เปลี่ยนแล้วคงส่วนที่กางและตำแหน่งเลื่อนไว้
3. ใช้ “เลือกหลายรายการ” เพื่อแก้หลาย entry พร้อม preview ก่อนยืนยัน การอ่านเป็นตัวเลือกแยกจากสถานะครอบครอง และมีไม่เปลี่ยนให้เลือก
4. ตัวกรองการอ่านอยู่ในปุ่มกรองบนชั้นตาม 0.8.6 เปิดกรองแล้วเลือกสถานะการอ่าน ใช้ยังไม่อ่านแทนค่าที่ไม่ได้ระบุ ใช้กับคำค้น/เรียง/ประเภท/รูปแบบ/แท็ก/ที่เก็บได้ ที่เก็บกับการอ่านต้องตรง entry เดียวกัน ไม่ซ่อนรายการที่มีแล้วจากหน้าเช็กก่อนซื้อ
5. CSV เพิ่มคอลัมน์ `readingStatus` หรือ `reading_status` / `สถานะการอ่าน` ใช้ enum อังกฤษหรือ label ไทยได้ (ตั้งใจจะอ่าน จากไฟล์รุ่นเก่ายังอ่านเป็น planned ได้) แก้ใน row review ได้ บ็อกซ์ใช้สถานะระดับทั้งบ็อกซ์จาก CSV (รายเล่มใช้ UI หรือ JSON backup) ตรวจผิดก่อนยืนยัน ไม่มีการเขียนทับ reading ของรายการเดิมจากแถว CSV ซ้ำ

## การเก็บข้อมูล

ตรวจ enum และสมาชิก box ที่ server ผ่าน validateState ใช้ JSON record/schemaVersion 2 เดิม ไม่เพิ่ม SQLite schema migration สถานะการอ่านตาม owner ผ่าน IndexedDB/outbox/revisions/conflict และ portable JSON/SQLite+photos backup เดิม ไม่มี API/AI หรือ public sharing เพิ่ม
