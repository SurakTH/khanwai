# ขอบเขตและความต้องการ

## ปัญหาและผลลัพธ์

อุปกรณ์เป้าหมาย: iPhone เป็นหลัก ต้องใช้ Android ได้ด้วย ไม่สมมติว่าผู้ใช้มีเครื่องยิงบาร์โค้ด การรับภาพจากกล้อง/คลังรูปเป็นเส้นทางหลักที่ต้องทดสอบบนเครื่องจริง

ผู้ใช้มีการ์ตูน นิยายวายไทย และนิยายแปลจีนประมาณ 200+ เล่ม จำเรื่องได้แต่เสี่ยงจำเลขเล่ม ฉบับ หรือคำสั่งซื้อที่ยังไม่ถึงผิด ต้องเช็กบนมือถือระหว่างซื้อ และจัดข้อมูลบนคอมได้

ผลลัพธ์หลัก:

- รู้ว่าเล่มที่กำลังจะซื้อมีอยู่แล้ว อยู่ในบ็อกซ์ หรือสั่งแล้วหรือไม่
- เห็นเล่มที่ขาดในช่วงที่กำลังสะสม โดยไม่เหมารวมว่าเล่มที่ยังไม่ออกคือเล่มขาด
- ลงหนังสือเก่าได้ทีละชุดหรือสแกนต่อเนื่อง ลดการกรอกซ้ำ
- เปลี่ยนเครื่องแล้วเข้าถึงข้อมูลที่ซิงก์แล้วได้

## ข้อกำหนดเวอร์ชันแรก

| ID | ข้อกำหนด | ขอบเขต |
| --- | --- | --- |
| R01 | บัญชีและความเป็นส่วนตัว | สมัคร/เข้าใช้/ออกจากระบบ ชั้นส่วนตัวและตรวจสิทธิ์ตามเจ้าของ |
| R02 | เช็กก่อนซื้อ | ค้นชื่อ ชื่อย่อ ผู้เขียน ISBN พร้อมสถานะมีแล้วและรอส่ง |
| R03 | จัดชุด | เรื่อง ฉบับ ภาษา เลขเล่ม เล่มพิเศษ และเล่มที่ขาด |
| R04 | เพิ่มหนังสือ | กรอกเอง เพิ่มช่วงเล่ม พิมพ์/สแกน ISBN และรีวิวก่อนบันทึก |
| R05 | ดึงข้อมูล | ค้น metadata อัตโนมัติหลังรับ ISBN ระบุแหล่งข้อมูลและข้อขัดแย้ง |
| R06 | AI ช่วยกรอก | อ่านรูปตามคำสั่งผู้ใช้ ให้แก้ก่อนบันทึกและกรอกเองได้เสมอ |
| R07 | ลงของเก่า | ถาดรอตรวจ แก้เป็นชุด สแกนซ้ำไม่สร้าง draft ซ้ำโดยไม่เตือน |
| R08 | ใช้ข้ามเครื่อง | เซิร์ฟเวอร์เก็บข้อมูลกลาง แสดงสถานะซิงก์ตรงความจริง |
| R09 | PWA | ติดตั้งตามอุปกรณ์ที่รองรับ เปิดและค้นข้อมูลที่เคยโหลดออฟไลน์ได้ |
| R10 | แก้ออฟไลน์ | เก็บงานรอส่ง ส่งซ้ำได้อย่างปลอดภัย และจัดการความขัดแย้ง |
| R11 | สำรองข้อมูล | ส่งออกและนำเข้าข้อมูลพร้อมการตรวจรูปแบบและ preview |
| R12 | รูปแบบหนังสือ | เลือกหนังสือเล่ม/ebook แสดงและกรองแยกกัน เก็บเรื่องเดียวกันได้ทั้งสองรูปแบบ |
| R13 | Docker เป็นทางหลัก | แจก app image และ Compose ที่เรียบง่าย ไม่บังคับ reverse proxy หรือบริการประกอบหลายตัว |
| R14 | สุ่มเรื่องที่ยังไม่อ่าน | เลือกจาก owned unread รวมบ็อกซ์ ตามตัวกรอง ไม่เปลี่ยนสถานะการอ่าน |
| R15 | ถังขยะและกู้คืน | รายเล่ม ทั้งฉบับ และรอตรวจ เก็บรหัส/รูป/สถานะเดิม ตรวจซ้ำก่อนคืน ใช้ซิงก์และ backup เดิม |

R06 ทดลองคุณภาพก่อนผูกผู้ให้บริการเข้าเวอร์ชันใช้งานจริง หากผลทดลองไม่ผ่าน ให้คงกรอกเอง/ISBN และแจ้งการปรับขอบเขต ไม่อ้างว่า AI พร้อมแล้ว

## สถานะของรายการ

- `owned`: มีแล้ว
- `ordered`: สั่งแล้วรอส่ง
- `wishlist`: อยากซื้อ ยังไม่ถือว่ามีหรือสั่งแล้ว
- `draft`: รอตรวจ แยกจากรายการในชั้น

0.7.0 เพิ่มสถานะการอ่านเป็นอีกมิติหนึ่งแล้ว: ยังไม่อ่าน / อยากอ่าน / กำลังอ่าน / อ่านแล้ว ค่าเริ่มต้นยังไม่อ่านตามคำขอใน 0.7.1 โดยไม่เขียนทับสถานะที่เลือกแล้ว ไม่ใช้แทนสถานะการครอบครอง ดู 12-reading-status.md

## ขอบเขตภายหลัง

ยังไม่รวม social feed, รีวิว/คะแนน, ซื้อขาย, แจ้งวันวางขายอัตโนมัติ, ติดตามพัสดุ, การยืมคืน, สแกนทั้งชั้นให้เพิ่มอัตโนมัติ และแค็ตตาล็อกสาธารณะที่ทุกคนแก้ร่วมกัน

## หลักการใช้งาน

- เมื่อค้นไม่เจอ ใช้คำว่า “ยังไม่พบในชั้นที่บันทึกไว้” ไม่รับรองว่าไม่มีจริง
- เตือนซ้ำแต่ให้เพิ่มอีกสำเนาได้โดยตั้งใจ
- “ขาดเล่ม” คำนวณเฉพาะในขอบเขตที่ระบุว่ามีออกแล้ว/ต้องการสะสม ช่องว่างในลำดับไม่ใช่หลักฐานการวางขาย
- แอพต้องใช้ได้เมื่อไม่มีรูปปก และไม่มีข้อมูลจาก API
- ชื่อจีน ชื่อไทย นามปากกา และชื่อย่อไม่ควรถูกตัดสินว่าเป็นเรื่องเดียวกันจากความคล้ายเพียงอย่างเดียว

## ตัวชี้วัดทดลอง

ใช้กลุ่มหนังสือตัวอย่างเดียวกันเปรียบเทียบเวลาลงด้วยมือกับดึงข้อมูล/AI บันทึกจำนวนช่องที่ต้องแก้ อัตราค้น ISBN เจอ และความผิดพลาดเรื่องเล่ม/ฉบับ เป้าหมายตัวเลขให้กำหนดหลัง baseline ใน Phase 0 ไม่อ้างเปอร์เซ็นต์ความแม่นยำล่วงหน้า
